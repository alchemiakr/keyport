# 합의된 범위

2026-10-19 HANDOFF와 사용자 결정에 따른다. 공개 `ajchemist/keyport`, MIT 라이선스, GitHub 작업과 커밋 작성자는 ajchemist다. 기본 UI는 한국어, Astro + UnoCSS, 미니멀 스타일이다. 의존성 설치·도구 실행·테스트·CI는 Bun을 사용하고 `bun.lock`으로 버전을 고정한다. Wrangler는 Bun 런타임 호환성 문제로 `bunx wrangler`가 공식 Node 실행을 따르는 예외를 둔다.

목표는 여러 계정 프로필·여러 Tailnet 연결을 관리하는 독립 Cloudflare 배포 PWA다. 첫 검증 흐름은 배포 → Access 인증 → 연결 하나 등록 → 발급·복사이며, 다중 연결과 운영 절차까지 구현 범위에 포함한다.

모든 허용 관리자는 모든 연결을 공동 관리한다. 계정 프로필의 예상 소유자는 관리자 입력·미검증으로 표시한다. 연결 검증은 대상 Tailnet의 키 목록 접근만 확인하며 실제 사용자 신원이나 발급 권한을 보증하지 않는다.

발급 계약은 사용자 API 토큰·일회용·사전 승인·비임시·태그 없음·24시간 고정이다. 감사 메타데이터는 90일 보관한다. 발급 결과는 복사 후 현재 화면에 유지하고 지우기·화면 이탈 시 제거하며 영구 보관하지 않는다.

설치는 Deploy to Cloudflare 버튼에서 시작해 브라우저 wizard로 진행한다. 배포자 자신이 필요한 Access/Secret 설정을 수행한다. 중앙 서비스나 런타임의 Cloudflare 관리 토큰은 없다.

실제 Cloudflare·Tailscale·기기 자격 증명이 준비되기 전에는 코드·자동 테스트·문서를 먼저 완성한다. 실제 배포·기기 등록·iOS/Android 독립 실행 검증은 별도 미검증 상태로 표시하며, 비밀을 채팅·이슈·PR로 받지 않는다.
